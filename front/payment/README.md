# Hermes Front — Payment Web UI

Este diretório conterá as aplicações frontend web do ecossistema Hermes Payment (Painel Administrativo, Portal do Merchant, Checkout Web).

## Estrutura Futura
- Painel Administrativo de Gestão do Tenant e Usuários
- Gestão de API Keys e Credenciais
- Portal Financeiro de Pagamentos e Conciliação
