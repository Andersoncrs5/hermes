# Hermes Payment — Documentação Técnica

Este diretório centraliza a documentação de arquitetura, contratos de API (REST OpenAPI / gRPC), modelo de dados e guias operacionais do Hermes Payment.

## Documentos
- `ARCHITECTURE.md`: Visão arquitetural, padrões Hexagonal/Clean Architecture e separação de módulos.
- `IAM.md`: Guia de Identity and Access Management, fluxo de autenticação, multi-tenancy e autorização.
- `SECURITY.md`: Políticas de segurança, hashing Argon2id, gerenciamento de tokens e auditoria.
